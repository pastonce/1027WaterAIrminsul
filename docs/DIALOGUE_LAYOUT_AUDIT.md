## 分段口径

仅句号（含非小数英文句点）、问号、叹号后的完整边界可切；保留闭合引号、括号、空格。候选须两段都能放下，选视觉字量差最小者，最多两段。允许一行与两行搭配；短段至少 6 字量且不小于长段 1/3，排除只有“好。”等悬殊短尾。纯逻辑字量中汉字 / 全角为 1，ASCII 为 0.55，默认两行预算 46；浏览器以 DOM 量尺优先。

不将逗号 / 分号 / 冒号 / 破折号 / 省略号当作分段点，连续英文点与小数点也不切；不擅自按字符兜底。短句或没有合适均衡边界的句子保持整句。当前 371 句均有两行内的完整方案，未来扩写若不满足应重新核查。段间 1500 ms、末段 2800 ms 与 450 ms 渐隐、悬停重计、同一编号事务保持。
