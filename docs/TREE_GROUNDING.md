# 引导、树苗落地与根部衔接复核

## 本轮呈现

种子、首次收露和首次浇灌统一使用局部微光圈、草叶细纹和轻触手势，不再显示文字提示条。轻触图案贴在目标旁，指针穿透，提示文字只供读屏；仅当前目标显示，首次成长后结束。波纹和手势为CSS / 小SVG，设置、后台、竖屏同步暂停，减少动态与强制色提供静态回退。

树对白相对此前向外移桌面38px / 横屏22px，仍保留屏幕安全边距，字号 / 两行宽度 / 播放机制不改。A～D树表情的局部间距改为桌面30px / 横屏18px；E/F沿用8 / 4px，纳西妲头部锚点与原间距不改。十点至十三点方向、避让顶栏 / 正文与原弹出时长保持。

## 前六次树苗的缝隙

原tree01 / tree1重绘轮廓的可见树脚比土坡中心接触面高，透明边界和原图附件位置并不完全重合；原附件矩阵只保证旧素材的注册位置。单独移动树干会使叶片脱节，因此在model组合层将这两种树体及对应叶片整体下移16世界单位，草坡不动；横屏按原场景比例折算。依实际附件生效，原切图前旧树苗仍保持同样偏移，切换到后续树体后不遗留修正。

原骨骼、关键帧、槽序、切图时刻、尺寸和回弹秒数仍保留，raw timeline及源文件不改。修正位于model层，因此实际绘制、命中和冠部落点共享同一形状。土坡底端继续贴屏，未缩小树或恢复镜头。

## D/E/F根部素材检查

并非误用旧版植物大战僵尸原图。运行时用的是世界树重绘WebP，问题来自主树干图片本身带根、另一个独立根领前景tree_overlay5～9又覆在草坡和主干上。两张独立重绘的根颈宽度 / 光脉不能逐像素相接，直接覆盖会叠出一层较硬的截口，放大后显得像另一块素材。

保留原树干、根领、草坡及原槽序；对共享根领前景上沿做固定局部柔化，让底下主干自然接入，保留外侧根须与花草。TreeRenderer共用一个1000坐标系SVG alpha mask：上沿约16%隐藏、至44%恢复实绘；同时clip掉完全隐藏上沿，避免其命中透明空白。此柔化固定在根领局部，不随成长改变透明度，不影响枝叶的原生切图 / 回弹，也不对整棵树或背景加滤镜。C中已出现的同类根领使用相同处理，避免D换景突变。

31张原稿、62份WebP、24张设备单档预载不变，没有新增位图 / 下载、Canvas、WebGL、RAF或存档字段。
