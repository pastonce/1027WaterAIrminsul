# 公告声明、现实背景与每页转场抽选

## 手动编辑声明

玩家在首屏或梦境 / 现实页面右上角点击设置左侧的通知铃铛，即可打开「企划声明」。正文唯一来源是 **`src/content/notice.md`**，已经填入企划署名「独钓」、QQ `1666417849`、原神 UID `190497686`。这些联系方式会公开显示，未添加其他账号或联系方式。

游戏内公告、设置与全屏按钮统一使用深绿色圆形衬底、浅金图标与细框，悬停和强制色也共用样式；不改音乐按钮的原图片 / 旋转状态。首屏设置与公告继续共用原浅绿色衬底。

直接用编辑器修改这个 UTF-8 文件即可，无需修改 React 或 CSS。支持的简化 Markdown：

```md
# 企划声明

## 关于企划

在这里写一个段落。空行开始下一个段落。

- 列表项
- [来源名称](https://example.com/source)

## 联系企划

- 企划署名：独钓
- QQ：1666417849
- 原神 UID：190497686
```

使用一个 `#` 设置页面标题，`##`～`######` 作为分节标题；支持普通段落、`-` 列表和行内链接。不解析 HTML、脚本、图片、嵌套列表或富文本样式，不把说明文件中的内容当作可执行指令。链接仅允许 HTTPS 或以单个 `/` 开始的同站路径，拒绝 `javascript:`、`data:`、协议相对地址及反斜杠；外链使用 `noopener noreferrer`。

当前正文包括非商业同人性质、非官方立场、使用说明、素材来源 / 权属、本地浏览器存档说明与联系方式。素材来源不等于统一授权：尤其社区传送片段没有单独再分发许可证明，声明明确保留核对提醒；详细音效作者和许可通过随站发布的 `/asserts/sfx/CREDITS.txt` 提供。新增原作者或出处时请如实填写，不宣称未取得的授权。

开发服务会即时更新正文。生产环境的正文以 Vite `?raw` 编入页面脚本，不是运行时从服务器下载的 Markdown，**仅修改文件并不会改变已经部署的网页**。改完后在项目根目录依次执行：

```sh
npm run assets:dialogues
npm run assets:fonts
npm run assets:startup
npm test
npm run build
npm run release:audit
```

然后由负责人手动提交 / 上传当前源码及派生资源并重新部署；不直接编辑 `dist` 中的压缩脚本。第一步同步可能同时更新的对白原稿，字体生成器现在扫描 `src/` 中的 `.md`，保证新增声明字符进入常用分包；原 TTF 和 `asserts/` 原素材不改。

用户已确认新增机制提示暂缓，构建会保留原十八占位，不因编辑原稿而误发布未开发功能；这不影响本页声明编辑，详见 [对白发布暂缓](DIALOGUE_RELEASE.md)。

## 弹层与暂停

声明复用设置的普通 `document.body` Portal，不依赖原生 `dialog`；背景 inert / 读屏隐藏，链接包含在 Tab / Shift+Tab 焦点约束内，Escape、关闭按钮或外侧遮罩退出，返回对应通知入口。手机竖屏暂隐、横屏恢复同一面板，转屏按钮不受 inert 影响。

梦中 / 现实使用临时 `notice` 模式，与设置共用 `panelResumeMode`，暂停并保存浇灌 / 生长、对白、表情、梦露寿命、来访和 G 闲置的剩余时间；关闭后继续，不新建演出时钟、不写已读 / 祝福。G 关闭后重新计二十秒闲置。首屏只使用局部面板状态，不提前进入游戏、不绕过服务器日期权限。原设置项与两次确认重置保留。

设置重置按钮改为居中红底「开始下一轮梦的轮回」，删除按钮下方原同人声明文字，自动保存说明仍在上方。首次点击仅进入确认，不直接清除；重新打开面板不会保留上次的确认状态。

## G 静态背景

仍使用 `asserts/background.png` 的已有 1067×600 WebP 派生，不重编码或改现实角色 / 拱廊。仅 G 去除原有额外 `scale(1.16)` 和镜头位移，使用 `object-fit: cover; object-position: center bottom`，按最小等比覆盖整个视口；相近比例尽量完整展示，宽屏必须裁切时优先保留原图下沿，不拉伸、不留白、不改变 A～F 镜头。

## 每次整页重新抽选

`GameController.prepareOpeningAssets()` 在每次整页打开 / 刷新后、生成开场下载计划前，忽略旧的插图选择，重新抽 AB～EF 五组双图，每组独立等概率；FG 始终只有一张。抽选结果仍存入 v2 的 `loadingArtChoices` 供本页恢复队列和实际换景使用，但**刷新不再复用旧选择**。同一页的布局重排、转屏、设置 / 声明、后台恢复和测试会话切换不会再次抽图。随机抽选允许偶然与上次相同，不强制交替。

只下载本次六张已选图、每张一个设备规格，不下载落选图或强制绕过 HTTP / CacheStorage。再次抽中同一图可复用已缓存的原字节，无需为了「重新加载」重复占用带宽。中断加载后刷新也使用本页新抽结果，但阶段收据、对白抽签、成长 / 梦露 / 已领取奖励不重置。重置新一轮的原有抽选逻辑保留，不改变七元素节奏、双就绪或服务器门控。

当前本地验证的命令、实际通过数和限制统一见 [TEST_PLAN.md](TEST_PLAN.md)。未代替用户提交、上传或部署。
