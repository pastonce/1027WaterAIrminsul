# 种子种植与首次交互引导

2026-10-26后续优化：普通触树 / G角色连续点击保留最新句并打断旧句，树表情累计7秒；Past可再次输入退出，普通页不显示测试标记。公告、设置与读信继续播放BGM，底层演出仍暂停。手机首屏保留完整圆徽 / 种子，A～D施法图案统一72%；详见DIALOGUE_SYSTEM / EASTER_EGGS / AUDIO_AND_FONTS / NAHIDA_BLESSING与最新TEST_PLAN。

## 玩家流程

1. 每页原技能揭幕结束后，新梦的“沉入梦乡”按钮下显示种子，附局部柔光和轻微浮动；不提前生成普通梦露或播放树对白。
2. 点击入口仍先验证服务器开放权限。成功进入时捕获种子真实屏幕中心和宽度，复用A背景的活动时钟，将种子从原位置平滑衔接到画面中央；背景真正就绪且约3.39秒原入场完成，才出现围绕种子的微光圈 / 草叶与轻触手势（无可见文字，保留读屏说明）。
3. 点击种子后1200ms垂直落入当前小山坡，在最后四分之一时间渐隐。期间不可重复点种或浇灌；减少动态为100ms短淡出。落地只提交种植收据，不消费梦露、不增加成长、不占用原生长节拍。
4. 种下后继续原A入场 / 读档欢迎机制。首次成长前，存露不足20时在首颗可收露旁显示微光圈 / 轻触手势；达到20时移至浇灌按钮的露水图标旁。两处均无可见文字，提示只供读屏。首次成长后两种提示均结束。

普通梦露仍每份随机4～6点、同屏最多7颗、5秒活动寿命。原20点浇灌预算、58拍、111稳定枝位、成长动画和后续阶段均保持。

## 状态与存档

v2新增严格布尔`seedPlanted`，新梦默认false；临时`seedPhase`为arriving / waiting / falling，完成后为null，不保存动画进度。

- 缺该字段且introSeen=true的旧版已入梦档，或任何已有成长 / 有效完成收据的档，兼容为已种植，不强制重播。
- 显式false且尚无成长的新档继续要求种植。落下中刷新不提前授予，刷新后再次等实际A入场并点种；落地后刷新不再显示种子。
- 原`hasLoadedSave`仍决定完成种植后播放初入句还是公共欢迎；未种下时两者均不抽取、不播放。普通树点击、来访、待机 / 表情和自然生物亦在种前停用。
- 首次收露 / 浇灌提示根据seedPlanted、growth和dew派生，不增加提示计数或存档版本。

## 暂停与实现

`GameController.planting`使用原PausableTimer，和presentationPaused同步；设置、公告、后台、竖屏暂停保留剩余落地时间。stop、重置、日期权限撤销清理旧回调。落下中开启减少动态，会改用短淡出并继续遵守暂停。

入口到中央的位移由DreamTreeScene现有onBackgroundFrame更新CSS变量，不使用独立墙钟；等待、静态回退及恢复沿用原背景就绪信号。垂落为CSS transform / opacity，普通提示指针穿透，种子保留原生按钮和键盘操作。没有新增Canvas、WebGL、RAF或树生长游标；固定根部 / 小山坡贴底不变。

## 素材

原图`asserts/seed.png`为白底，保持原文件及哈希不变。使用内置image_gen仅提取原种子透明底，不重新设计形状 / 配色，也不把辉光烘入图片。

- 透明工程稿：`asserts/seed-cutout/seed.png`。
- 发布副本：`public/asserts/ui/seed-7bdcd8bf652d.webp`，256×372，21644 B。

执行`npm run assets:seed`可用本地去底稿重建透明WebP；若更换原种子，脚本先检查源哈希，要求同步更新去底稿。之后更新字体、startup并构建。开场只下载压缩单份，不请求约2.7MB的白底原图或约1.2MB的透明工程稿。
