# 阶段换景加载页

真实加载开始时播放一次本地传送片段；仍等待原门槛 / 旧对白 / 来访全序列完成，不因进度跳变、新景就绪或普通刷新重响。加载期间拒绝其余交互音效，后台 / 竖屏停止不补响；声音失败不阻塞遮盖或解锁。原神社区音源及上线许可注意见 INTERACTION_AUDIO.md。

## 条件与顺序

本页取代旧的“边界立即换景、不等对白”描述。普通对白 / 来访仍非阻断；只有真正换景才短暂覆盖加载页，没有确认按钮。 时间表以 project_prompt.md 最新交互修订（§七十四）为准：25 日 10:27 A→B→C（180 / 340 / 520），26 日 10:27 D→E（680 / 840），27 日 13:27 F（1027），G 在最终梦醒后进入。均为北京时间，同批权限仍逐段推进；整页权限上限为 0→520→840→1027，祝福不越所属段。 同批日期不取消 A→B→C、D→E 的独立加载；G 后无新阶段。A 未开放不通过加载流程进入梦境。

1. 当前段达到上限、有completedStages完成资格且目标日期开放；生产权限仍只用ServerClock.permissionNow()。正常日期已开时达到上限即可记完成，不再越界。
   下一日期未开可达上限但不记完成；之后日期开放 / 刷新不自动转段，补浇扣20但不增加成长 / 动画 / 来访，仅记完成。上限180 / 340 / 520 / 680 / 840 / 1027，F祝福最多1020、末次浇至1027且不长树；旧完成收据安全迁移。
2. 旧背景保持，播完已预约树回应 / 欢迎 / 待机、来访 / 祝福 / 停留 / 离场，含全部分段、鼠标悬停保留和最终淡出；中间换段不算原句完成，此时不播转场句。已有完成资格等待不再添加免费回应或越段扣费；锁日期已满可观赏浇灌但不来访。
3. 从目标段池预选一句保存：A→B 用 B/Z，依次至 E→F 用 F/Z；G 无专池，F→G 暂用 G/nahida，角色旁播放。仍先覆盖插图，120 ms 后更新 stage / 请求新背景，常规加载后才播；首次 F→G 还需 6 秒黑屏 / 眨眼完全结束。旧已预约来源段句保留兼容，不重抽；A 转场只供无档首入。
4. 目标首帧实际绘制 / 当前静态回退完成，且转场插图已解码或明确失败，才算就绪；再等既有 900 ms 快照接力。常规至少 1800 ms，并完成末元素的唯一一次中点停顿；最后半枚跳满后全彩停 180 ms、淡出 280 ms。没有宽度平滑插值，减少动态也跳过覆盖淡出。
5. 常规加载完成保存 sceneStage、恢复输入后才播目标段转场句。首次 F→G 特例：插图下已备黑屏，加载后进入 waking，三次睁眼全部完成才写 G 收据并播放原定入场句；刷新重演未完成梦醒、已有 G 不重播，见 REALITY_CELEBRATION.md。无放回轮次 / 待播游标保持，整个覆盖期间暂停游戏活动寿命，不吞已存资源。

STAGE_LOADING_ART 已接入 AB / BC / CD / DE / EF 各两张、FG 一张，共十一图。每次整页打开 / 刷新都重新预选并保存 loadingArtChoices；同页布局 / 面板 / 后台恢复不重抽，重置也重新抽取，允许偶然抽到相同图片。开场集中下载本次六张已选图的一种分辨率，复用有效缓存，运行时仅当前 / 下一张参与解码。图片等比 cover 铺满整个屏幕，取消四周边距与下方白区；七元素仍在原下侧正中、叠于图上，不改位置或节奏。CD2 派生从左裁 580 px、运行时右对齐，屏幕需要时继续左裁；失效继续白底。规格、预取和哈希见 PAGE_ASSETS.md。首次入梦、面板、普通浇灌和梦境回望不触发。玩家 / 读屏不显示内部阶段、名称、成长或百分比。

## 图标与非匀速进度

依据用户补充的 [CodePen 源码](https://codepen.io/jiazengp/pen/dyWvxem) 横排七元素，原 Pen 本轮 403，未执行远程脚本。其 [图标地址](https://yuanshen.site/imgs/loading-bar.png) 实际返回 1024×128 WebP、50168 B，来源 / 哈希 / 权属说明在 asserts/reference-supplements/loading/README.md；源 / public 字节一致。

SVG 亮度遮罩去掉黑色部分，底层淡灰、前层从左到右按火 / 水 / 风 / 雷 / 草 / 冰 / 岩分段：

`#EC4923` → `#498FCC` → `#359697` → `#6957C2` → `#66AD16` → `#35AACC` → `#CC9046`。

图标在下侧正中，桌面宽至 400 px、矮横屏至 350 px，窄屏缩放。按最新反馈改为**停顿占绝大多数时间，推进以不规则大幅跳变为主**：前六元素基准停顿 100 / 650 / 820 / 120 / 560 ms、增量 0.12 / 0.29 / 0.025 / 0.345 / 0.12，再各加 ±20% 随机扰动；既有大跨越，也有一次很小的试探推进，不做 CSS 线性补间或无限循环。

最后一枚直接跳至实际图形正中，**仅停顿一次 1100 ms** 后跳满，不在末枚其他位置新增停点。本地亮部包络为 [920,1013)，中点为图宽的 966.5/1024，不以等分七栏代替视觉正中。若真实背景仍未就绪，只延长同一次中点停顿；即使资源提早就绪也保留这次长停顿。常见资源已就绪时约 4 秒结束，随机脉冲及真实资源等待会改变总长。**这是表现进度，不是下载字节百分比**，真实背景未完成绝不填满。图标异常的本地七色圆点共用各图形中心和同一裁切，末枚仍在正中停顿，不提前全彩，也不阻止解锁。

只增加 SVG / CSS 与可暂停 timeout，不新增 Canvas、GL、RAF、全屏滤镜或粒子；压缩资源已集中预载，仍只实例化 / 解码当前背景。

## 恢复、暂停与降级

- v2 的 sceneStage 仅新景完成保存；加载中刷新恢复已选文本，不重抽对白 / 重扣 / 重赠；插图按本页新选择，可与中断前不同。新转场属于目标池，旧已预约来源池仍可恢复；pendingDialogues 保留实际来源 / 目标 / lines / cursor。opening 为无档 A 专用，读档取消并播欢迎；场景收据不授予日期权限。
- 初始校时在启动黑屏内完成时，可在揭幕背后恢复服务器已许可且曾展示的场景，不重演历史阶段；校时晚于揭幕结束时，仍先等当前对白，再一次加载至可恢复场景，不逐段重跑。权限暂时钳制较早场景不覆盖更后的历史收据；真正新阶段仍逐段门控。
- 权限撤回取消加载和旧回调，显示钳制但保留资源；回调校验事务 ID / 目标。旧背景状态不能冒充新景就绪。
- 后台 / 竖屏暂停进度与完成时钟；竖屏让位给原转屏层，按钮在 inert 内容之外，不锁死。新阶段暂停背景动画但加载后仍绘制真实首帧。
- 转场插图失败或 10 秒超时回退白底，独立确认 artworkReady；场景静态图失败依次回退底图 / 渐变，图片最多等待 10 秒，动态背景沿用 20 秒超时。只在插图和新场景都确认后释放，不沿用旧事务或旧 ready。
- 卸载、退出、重置、撤权清理加载计时；原图片 / 背景请求、监听和 GPU 资源按各自生命周期释放。
