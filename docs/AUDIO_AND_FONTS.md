## 播放规则

- 音乐默认开启，v2 `settings.music / musicVolume` 默认 0.45。交互音效改用真实素材，新档 `sound / soundVolume` 默认 true / 0.6，旧显式关闭保留。分别设置「背景音乐音量」「交互音效音量」，均调 0 静音、保留上次正音量，调大启用；两者独立，右上音乐按钮不影响音效。非有限值回默认，其余钳位；音效细节见 INTERACTION_AUDIO.md。
- 受浏览器自动播放政策约束，首次真实点击 / 键盘手势先以极短静音 WAV 授权媒体与共享 AudioContext；自动播放授权后仍留白**8秒活动时间**，但直接点击音乐播放 / 重试按钮立即请求并渐入，不额外等待8秒 / 12秒。不会绕过浏览器政策。开场优先下载当前阶段一首压缩M4A，不实例化媒体 / 解码；命中版本CacheStorage后只为当前曲建立Blob URL，换曲 / 卸载撤销，缓存读取200ms有界回退到原URL流式播放。七首不同时预载，源文件 / 音质规格不变。
- 同阶段单首播放，**不使用原生 loop**。曲终后静默 **12 秒活动时间**再从头播放；刚入页、切换目标场景先留白 8 秒。留白在后台、竖屏和加载演出期间暂停；公告 / 设置 / 读信期间正常推进，恢复后只走余量。
- 渐入 1800 ms，曲尾最后约 2200 ms 渐出，换曲旧曲 1200 ms 渐出；手动暂停 / 旧归档模式暂停 350 ms 渐出后保存当前位置。后台、竖屏或揭幕锁定立即静音暂停，返回不补播离开期间的时间。恢复同一曲从原位置渐入，不重新开始。
- 开场 intro、设置、加载页、梦醒期间不启动新曲；G 梦醒完成后留白再播放本地生日曲。默认音量为 0.45，设置可调至 100%，不修改源文件响度；播放中改音量以 150 ms 平滑调整，不换曲 / 重置当前位置。加载 / 解码或缓冲 15 秒仍未恢复则停止并提供按钮手动重试，不后台无限重复请求。
- `MusicManager` 仅复用一个流式 HTMLAudioElement，不全量解码曲目。与真实音效共用 AudioContext，各有独立 GainNode；音效额外限并发 / 轻压缩，不改 BGM 音量。无 Web Audio 时音乐用短时 timeout 回退音量，音效静默；不增 RAF、画布或 WebGL。停止 / 卸载清理媒体、计时与节点。

右上角原设置入口改为音乐按钮，直接使用原 `button.png`；深绿底盘、浅金描边 / 局部光影保证不同背景的对比，图片不改写。源图不透明度最大仅 14/255，显示时以局部 SVG alpha 增益 18 倍还原清晰纹样，再提亮为浅金；不放大整页光影、不新增画布。仅媒体实际播放时持续旋转，暂停、留白、加载、失败和无音乐时静止；减少动态时不旋转但仍可播放。按钮有键盘与读屏名称，暂停偏好可刷新恢复。右上另有直接 **设置** 入口，设置不再展示梦境手记、口令及归档；音效、语速、减少动态、校时、重置均保留。浇灌 / 生长中设置也可响应，暂停剩余演出而非等待或被旧定时器关闭；面板间切换不恢复游戏时钟，关闭后回到设置按钮焦点。waiting时按钮可直接提前开播，实际播放中点击则暂停。按钮的原生悬停 title 与 aria-description 在留白 waiting、请求解码 loading、播放中缓冲 buffering 时统一显示「兰那罗们正在练嗓...」；其余保留播放 / 暂停 / 重试名称，loading / buffering 才标 aria-busy。内部依据真实 media / Promise 状态，不估算网络进度。设置采用 document.body 下的 React Portal 兼容弹层，不调用原生 dialog.showModal / open；背景 inert 与 aria-hidden，保留 Escape / Tab / 外侧关闭及焦点恢复，不受场景裁切 / 堆叠影响。竖屏隐藏弹层但保留面板状态，横屏恢复，转屏按钮始终可用。 既有音乐暂停 / 音量偏好不变。

## 字体

最新两条交互声（来访魔法竖琴 / Rainstorm 短雨）沿用原 SoundManager / 交互音量与共享上下文；七份压缩数据共 200,687 B，不新增 BGM、播放器或预解码，详见 INTERACTION_AUDIO.md。此前百分比小轮未重生字体且按要求免测；本轮新增声明后已重生字体、运行构建 / 回归，未进行新音效主观试听。

三份 TTF 为同族不同轮廓缩放，选择居中的 `asserts/字体/原神0.87.ttf`（HYWenHei-85W），保留原文件、内部名称与作者信息。原 7,070,716 B、33,477 个 Unicode 映射，派生为相同字形的两份 WOFF2：

- 常用包 **208,664 B**：扫描当前 `src/` TypeScript / JSON / CSS / Markdown 与 `index.html`，包含最新全部对白、四年生日来信、企划声明、界面和常用字符；首页只预载这一份。
- 扩展包 **3,320,320 B**：其余映射，CSS `unicode-range` 与常用包互斥，仅文本需要罕见字时请求；两包合计覆盖源字体全部映射，不牺牲用户输入覆盖。

`src/styles/fonts.css` 生成统一别名 `Irminsul`、`font-display: swap`，页面正文、英文、数字、输入框、按钮、调试面板和对白编号均使用该族；姓名保留合成加粗。字体尚未加载或失败可系统字体回退，纳入开场集中准备，失败可回退、不永久阻断揭幕。气泡仍固定两行，字体就绪 / 尺寸变化由真实 DOM 重新量尺分段，不更改原文、编号、语速或角色摆位；已发布的全部 371 句需在新字体下复验。

路径见 `src/data/fonts.generated.json`，完整源 / 输出哈希、字符覆盖和范围见 `font-assets.manifest.json`。字体压缩不改字形；不代表新增字体授权，发布前仍由负责人确认音乐、按钮和字体使用许可。 本轮新增可编辑企划声明，并保留本轮暂缓的新增机制原稿，已重新生成分包、清理无引用的旧发布哈希；源 TTF、字形和正文 / 气泡宽度不改，实际复验范围见 TEST_PLAN.md。

## 再生成

```sh
npm run assets:music
npm run assets:sfx
npm run assets:fonts
npm run typecheck
npm test
npm run build
npm run test:e2e -- music-fonts.spec.ts speech-playback.spec.ts dialogue-flow.spec.ts
```

音乐脚本需要本机 FFmpeg，可设置 `FFMPEG_PATH`；本次仅在忽略目录 `.asset-work/audio-tools/` 安装固定 `imageio-ffmpeg==0.6.0` 的 FFmpeg 工具，没有修改系统 PATH、全局 Python / npm 或新增应用运行依赖。编码选项参考 [FFmpeg AAC 文档](https://ffmpeg.org/ffmpeg-codecs.html#aac)，工具包见 [imageio-ffmpeg 0.6.0](https://pypi.org/project/imageio-ffmpeg/0.6.0/)。字体脚本需要 Python、fontTools 和 Brotli；本机已有。普通开发 / 构建直接使用派生文件，服务器不必安装这两个工具。

增改对白 / 界面字符或替换字体后重跑 `assets:fonts`；增改曲目后重跑 `assets:music`。先生成再构建，生成清单随源码一起保留；哈希发布文件可长期缓存。不得把原 MP3 / TTF 或本地工具整目录塞进 `public/`。本轮实际测试、失败修订与验收边界见 [TEST_PLAN.md](TEST_PLAN.md)，仅本地开发，未发布。
