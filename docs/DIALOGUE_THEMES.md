## 方向与范围

在同一套叶角细框、菱形徽记、姓名分隔线与两行正文骨架上区分叙事性质，不增加标签、确认按钮或剧情弹层。联网检索了[官方纳西妲角色介绍卡](https://genshin.hoyoverse.com/en/news/detail/25037)及[3.2 官方活动页](https://webstatic.mihoyo.com/ys/event/e20221024prev/index.html)，参考草木、浅色纹样和金线装饰语言；这是本项目的适配设计，不宣称复刻官方对话 UI。Game UI Database 本次抓取失败，没有从中下载或搬用素材。

不下载新图片、字体或脚本。保留原 `asserts/dialog.jpg` 及其 27,582 B 发布 JPEG；纳西妲徽记复用既有 `DENDRO_ICON` 草元素图标，其他枝叶、星芒、几何节点、糖果、缎带蝴蝶结与花瓣由小型静态 SVG 路径绘制。原素材、源哈希和图片清单不变，原图出处仍见 PAGE_ASSETS.md / E_SKILL_PATTERN.md。

## 排版与可读性

- 全部气泡桌面外宽 326 px、14 px 正文 / 26.6 px 行高，正文固定两行；手机横屏 10.5 px / 17.5 px、外宽 236 px。指定参考句均恰好两行。内边距、正文有效宽度、隐藏 DOM 量尺不变，不为装饰挤窄正文或改变分段。
- 姓名仍加粗，树名仍为「梦中的世界树？」；姓名左侧小徽记 22 px、手机 16 px，右侧细线承担层级，不增加主题名称或解释文字。右下低透明枝叶 / 星轨 / 几何纹位于正文后面，不遮字、不截字。
- 深色主题使用接近不透明的局部纸面与浅正文，避免不同场景使文字忽亮忽暗；机制使用柔红而非危险警报红，没有感叹号、闪灯或告警措辞。庆典在同一叶角细框内使用奶油彩纸、粉 / 金 / 薄荷 / 浅紫；左侧包装糖果徽记，右上礼物缎带蝴蝶结，右下花叶缎带 / 彩纸星点。装饰绝对定位、不挤窄正文、不压住姓名；与其他四框保持同一骨架，不做循环闪烁。
- 草纹保持可辨识，浅色覆层当前约 **66%～74%**，配墨绿文字；G 用户 / 回复不再填此 JPEG，而使用自己的明亮多彩底。森林、金色与红色主题没有额外背景图片。
- 主题边框、尾尖和阴影配套变色，左 / 右 / 下方气泡均保持原方向。只增强局部对比，不恢复全屏遮暗、背景滤镜或大面积光晕。
- 强制色模式统一使用 Canvas / CanvasText、隐藏装饰；减少动态无需额外动画回退，因为新装饰完全静态。正常模式只沿用原 450 ms 淡出，不新增循环动画、backdrop-filter、画布、WebGL 或 RAF。

## 生命周期与验证

带小三角的表情气泡为独立、无文本的 DOM 图像层，不占这五套正文框的宽度 / 高度。G 用户 U 不触发，回复 / 日常只在原稿选中的一个时刻弹一张，数字标记仍不显示；桌面 96px / 横屏 70px、真实树顶 / 头部十点至十三点留距摆放，另避开正文；不改主题路由或两行排版，见 EXPRESSION_SYSTEM.md。

装饰容器读屏隐藏、禁止指针，不增加焦点或按钮；原 live status、逐字停顿、悬停重计、两行测量、后台 / 设置暂停、末段结束后才祝福 / 换景保持。主题仅为临时呈现，不写档、不改变来访、音乐或服务器日期。

入口：`src/game/dialogue/dialogueTheme.ts`、`src/components/DialogueBubble.tsx`、`DialogueOrnament.tsx`、`src/styles/dialogue-themes.css`。旧 interactions.css 的 speaker 配色已移除，避免 G 回复被旧规则覆盖。原两行几何与计时仍归 interactions.css / textPlayback / SpeechDirector。

浏览器对正文 / 主题基准底色检查至少 7:1、姓名至少 4.5:1，并检查实际两行 / 不裁字；这是本机样本和指定色对的检查，不等同完整 WCAG 或所有动态背景像素的合规认证。真实手机 / Safari、视觉体感和低字号舒适性仍需试玩。
