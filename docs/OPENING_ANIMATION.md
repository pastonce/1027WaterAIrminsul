# 每次打开网页的技能揭幕

当前四叶印与光线采用E技能clean-v2分离图集；单印无残线、四角完整，中心纹样 / 原世界几何 / 方窗 / 轨迹及全部时长保持。新哈希PNG84838B纳入集中预载，原图保留；重建与对照见E_SKILL_CLEAN.md。

## 最新流程

整页打开 / 刷新播放一次；点击「沉入梦乡」、换阶段、设置、回望不重播。进入临时 test 会话也不重播。基础图案与原 5800 ms 轨迹复用，但总时长现在取决于真实资源准备，不再是固定 5.8 秒。

1. 黑屏；技能框右上角 corner_tr 四叶印从左屏外抛入，恒定尺寸、仅平面旋转。
2. 原 600 / 1150 / 1452.5 ms 三次主触底位于屏宽 16% / 27% / 34%，运动锚线为屏高 50%；第三次主触底后再微弹三次。竖直回弹速度保留 55%，横向保留动量、落稳直接滚动。
3. 2850 ms 滚到中央，沿惯性继续以 90°/s 缓转，下方出现统一资源准备条，其下显示同一真实进度取整的 0～100% 数字；两者共用挂载条件、同时出现 / 消失，不重复读屏播报。真实页面仍完全裁切、不可交互。至少保留 600 ms 中央展示，不伪造进度或循环假加载。
4. 资源尝试全部结束后同时隐藏进度条与百分比，按当前角度顺向滑行，再用 300 ms 匀减速停到下一个合适的 90° 整数倍；不逆转或瞬间吸附。滑行加停转不超过约 1.3 秒。
5. 接回原四角分裂、真实页面方窗揭示与等比扩框；中央纹样渐隐，全部临时实例删除后开放交互。

停转后的相对时序如下，真实页面只裁切、不截图 / 缩放：

| 相对时间 | 画面 |
| --- | --- |
| 0～520 ms | 单印淡出，四角分裂，珠链和边线出现 |
| 440～760 ms | 框内现出原页面 |
| 980～1760 ms | 边框和真实方窗同步等比扩出视口 |
| 1660～2240 ms | 中央纹样渐隐 |
| 2350 ms | 清理遮罩、裁切、计时器与全部开场 Animation，恢复输入 |

缓存热启动通常约 6～7 秒；慢网额外等待真实下载，不根据固定演出时长假定资源已完成。下载总等待有 60 秒上限，失败项之后仍可走原懒加载 / 静态回退。揭幕后新档种子出现在入口下方；点击入梦复用实际森林镜头时钟衔接到中央，种下后才进入收露 / 首次浇灌引导。A 初入 / 欢迎对白另等实际森林就绪、共享镜头下移结束及种植完成；日期未开放时仍只能停留入口提示。

## 资源与实现

- 复用原 E 技能本地图集、四角 / 珠链 / 边线和中心纹样；单印取 [620,4,180,180]，素材整体仍缩小 20%，原文件及 UV 不改。
- 原 12 条 Web Animations 到中央时冻结，同一单印由一条缓转动画接管；完成后用一次停转动画交还原时间线。无新增 Canvas / WebGL / RAF，不逐帧更新 React。
- 末段角速度连续衔接 90°/s 缓转；此前弹跳 / 横移共用原连续曲线，尺寸恒定，不做透视压扁。
- OpeningReveal 裁切真实 App；窗口与技能框几何 / 扩张缓动一致。resize 仅更新几何 / 关键帧，不重播。
- StartupLoader 在开场挂载后启动三路下载；仅选本设备需要的资源 / 转场规格，压缩响应进入版本化 CacheStorage，不创建未来场景实例、批量解码图片或音频。开场仅预载当前阶段压缩BGM、其他曲目流式按需，扩展字体按需。详见 [集中预载](STARTUP_ASSETS.md)。
- 资源目录 / 大小 / 哈希来自 assets:startup，每次整页打开 / 刷新在下载前重新预选并保存六组转场图，同页固定、命中缓存可复用。普通阶段加载页的七元素长停 / 大跳机制完全独立，不复用启动揭幕。

## 暂停、输入与降级

- 游戏 start 前挂起探索、对白、成长、祝福与解锁表现计时；服务器校时照常，不把资源准备当成权限。
- 实际 App inert / aria-hidden，开场覆盖层拦截鼠标 / 触摸 / 滚轮 / 普通键盘；浏览器快捷键保留。竖屏转屏提示独立 Portal 到 body，位于开场遮罩之上，不在 inert 子树内，可点击和键盘操作。
- 后台 / 竖屏暂停原动画、缓转、停转和 PausableTimer，恢复继续；下载可以继续，不因回到前台重下整套资源。
- 减少动态、图集解码失败 / 900 ms 等待超时、无动画 API 或创建动画被拒绝：显示静态四叶印和资源条，资源准备后使用 220 ms 淡入 / 安全放行，不永久黑屏。
- 每文件 10 秒、全局 60 秒有界等待；失败不阻断交互，剩余文件交原懒加载重试。缓存不可用或配额不足退回浏览器 HTTP 缓存。
- 结束 / 卸载清理临时动画、下载、计时和事件监听；不留下普通页面的暗罩、输入锁或持续空转实例。无 GL 的后续场景使用原真实 poster 回退。
