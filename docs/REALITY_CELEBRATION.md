`WakingDirector` 使用一个 `PausableTimer`，全程 **6000ms**：黑屏 600；第一次睁开 700 / 停留 350 / 闭合 450 / 黑屏 300；第二次睁开 850 / 停留 450 / 闭合 500 / 黑屏 300；第三次睁开 1300 / 落稳 200。单个 SVG 亮度遮罩用椭圆眼缝，前两次分别露出约视口高度 20% / 57%，第三次覆盖四角并移除遮罩。真实 G 页面不缩放，不复制截图、不增画布 / GL / RAF。

黑底在插图释放前已位于其下，不会闪现无遮挡 G。输入 inert / 读屏隐藏、演出获得焦点，后台 / 竖屏暂停眼睑与计时；竖屏仍可操作转屏按钮。完成后删除节点、恢复角色焦点并播放原定转场句。系统或站内减少动态时使用 650ms 黑底柔和揭开，中途开启也可平稳放行。

## 祝福、送礼与彩雨

点击祝福后仍预约原 U / N 两句，各池独立无放回：

1. 用户 U 开播时，**3 个枣椰蜜糖 + 4 个哈瓦玛玛兹**与屏幕上方的彩带 / 糖果雨同时开始。七份礼物每份错开 190ms、沿不同弧线从用户侧送到纳西妲身前，约 3.7 秒内收束；仍只复用两张透明图 URL，不增加贴图种类或改变整场 4800ms / 原回复门控。装饰不消耗资源、不新增台词 / 确认。
2. 每次桌面 120～168 片 / 手机横屏 76～108 片，使用十四种更明亮的粉、珊瑚、橙、金黄、薄荷、青蓝与紫色。落点无等距栏，延迟连续随机至 1200ms，下降时长 2700～4200ms；全部在 **4800ms** 前退场，不循环追加。左右风偏 / 摆动、旋转、大小和糖果比例分别抽取，同次重排保持原轨迹。
3. 竖向位移仅起点 / 终点、linear 匀速；横向飘动 / 旋转放在内层独立动画，平滑转向，不再将中途较短的纵向路程接到较长路程造成突然加速。单次 CSS transform / opacity，不增加画布 / GL / RAF。
4. U 全部分段、阅读停留、悬停与 450ms 淡出，以及这次同步彩雨**二者均完成**后，才播放原定 N。U 较短只等彩雨余量，不从头重播；U 较长不额外等待一整场彩雨。完整 U / 同步演出 / N 流程结束后才从零计 G 的 **20 秒**闲置。

`SpeechDirector.prepare` 只在原句开播前执行一次，不随重分段 / 字体重排 / 语速重播重复送礼；持有未完成事务等待彩雨，延续原 read / fade / complete 边界。`BirthdayDirector` 仍只有一个可暂停计时器，gifting 表示同步甜点与彩雨，wait 仅登记原回复继续回调，不重置计时；shower 只用于旧游标已读 U 而彩雨未完成的恢复。装饰指针穿透、读屏隐藏，无运行时画布 / GL / RAF、循环粒子或新库。

粒子使用独立的庆典 ID 伪随机源，不消耗对白 / 来访的随机抽选。每次祝福布局不同，同一次重排或暂停恢复保持原轨迹，不在 React 渲染时重新随机。减少动态仅保留十二片静态彩纸 / 糖果淡入淡出。

设置 / 后台 / 竖屏暂停 CSS 与剩余时钟；减少动态改为 650ms 静态甜点 / 分散彩纸淡入淡出，不下落 / 飞行。失败图片隐藏且不阻断对白。重置、日期撤回、回望、stop 取消临时动画及旧回调。

v2 待播 `wish` 可选字段 `celebrationComplete: true` 仅表示本次演出完成，在实际彩雨结束时便保存，不必等 U 读完。只接受 wish 的严格布尔 true。未完演出 / 未读 U 刷新可重播同步演出；已完成演出不重播，即使 U 仍未读也只恢复原 U。旧 U 已读 / 演出未完只补彩雨与原 N；已完成且 U 已读则直接恢复原 N。不增加存档字段、不重抽 / 改已读 / 赠长。
