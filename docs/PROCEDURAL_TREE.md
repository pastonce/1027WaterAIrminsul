# X05 Irminsul临时程序化树

## 输入与生命周期

用户本轮明确要求实现X05，因此Irminsul现已成为真实彩蛋。A～F已种植且开放的梦境中直接键入`Irminsul`，或在设置的原无提示输入框输入；不区分大小写，同时兼容原稿`I-r-m-i-n-s-u-l`的逐字拼法。再次输入还原，刷新或重置退出；G与尚未种植时不触发。

仅GameSnapshot新增临时proceduralTree布尔值，GameSave / v2不加字段。切换不消费梦露、不改变成长、概率 / 抽取轮次、已读、预约来访 / 祝福、阶段或服务器时间，不自动开启test。保持默认树时原58拍 / 111枝位完全不变。

## 旧版形态来源与适配

从本地Git提交3107cdb中的TreeRenderer.tsx / tree/geometry.ts恢复程序化树的绿色木质渐变、弯曲主干、30条交错枝、每枝7叶、25片上冠与旧金叶 / 风铃细节。现在使用新模块procedural.ts与ProceduralTreeArt.tsx，保留种子驱动的确定性构型，没有重新依赖已删除的旧镜头或树冠 / 根部位图。

为适配固定地面，将枝位纵向间隔压缩并限制成熟主干高度710世界单位；根仍锚在3300、原土坡继续贴屏，不缩放背景或恢复移镜。叶片渐长采用局部scale，枝干沿路径舒展，树冠叶片分批长出；没有新增整体透明命中框、Canvas、WebGL或RAF。

两种形态共用TreeRenderer既有唯一GSAP游标。proceduralGrowthAtFrame将58拍的当前index / time按每次20点的真实时长映射到同等成长；C/D多拍连续，E/F两拍继续有成长表现。切换时不重挂Renderer或重开tween，面板 / 后台 / 竖屏保留剩余进度；最后1020→1027仍不生长。

## 配套交互

- 点树、键盘、对白与浇灌使用原控制器；SVG只让实绘枝干 / 叶片接收输入，透明空隙穿透，土坡仍不拦截。
- 树对白、表情和祝福扫描框按当前形态的真实冠部包络定位，施法发射点仍取纳西妲躯干。
- 晶蝶保留原种子、解锁阈值、形象 / 大小 / 相位；程序化模式绑定到对应的稳定枝叶，不再次随机。切回恢复原枝位。
- 程序化冠枝在既有480世界单位的保守梦露避让包络内；土坡不变，因此继续沿用该包络，不重排现有梦露或改变奖励寿命。

代码来源及适配均为本地，无额外下载。实际验证见TEST_PLAN.md，测试截图在artifacts/irminsul；未代发布。
