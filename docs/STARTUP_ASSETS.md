# 开场集中预载与浏览器负载

## 成功才揭幕

开屏百分比只表示当前所选压缩资源已收到的真实字节，最高99%，直到全部文件完整成功且所需运行时模块导入成功才100%并继续原揭幕。失败、204、HTML错误页、空响应或截断200都不能当作成功。此规则覆盖旧“尝试完成 / 总60秒后放行”机制。

保留三路下载。每个请求等待响应头及每个流块的无进展时间最多30秒，每收到新块重新起算；正常下载可以超过60秒，不按总墙钟提前终止。每文件最多三次尝试，间隔800 / 1600ms，第二次起使用reload避开坏HTTP缓存。一项耗尽后停止派发新的文件，收束当前请求，避免离线时逐一等待整份目录；留在黑底加载页显示“部分素材未能加载”和“重试加载”。点击后已完整缓存的文件直接复用，只补缺失 / 无效资源，不进入半加载的游戏。

运行时导入也必须成功，单次30秒有界、最多三次，失败进入同一个重试状态；不静默吞错。取消 / 卸载中断网络与等待、取消延时，旧进度不得回写。错误按钮支持键盘Tab / Enter，不把底层页面解除inert；后台 / 竖屏继续沿原机制暂停演出，下载可继续。真实资源成功后才触发原停转 / 分裂 / 扩框，不重播首次公告或改变存档。

每次整页打开 / 刷新，prepareOpeningAssets忽略旧插图并重抽五组双图、FG固定；同页与重试不重抽、不改变成长 / 台词 / 来访。startupPlan按设备尺寸、像素密度、减少动态固定选择一档，不同时下载多个设备档。

当前阶段BGM只预载一首压缩AAC，不创建媒体或提前解码；其他六曲流式按需。排除落选插图、另一尺寸、扩展字体、原MP3 / TTF / 视频、许可文档与工程截图。2026贺图已生成768 / 1280两档，开场只选当前设备一档下载，阅读时仅解码当前年份。

加载仅下载压缩响应，未来场景不提前实例化或解码 / 上传全部纹理。当前背景和角色在真正进入时才建立既有播放器；移动WebGL不可用或上下文丢失时使用对应姿态 / 场景poster，并可有界恢复，不回退到彩蛋。

## 缓存和校验

assets:startup生成大小目录与SHA来源清单。版本CacheStorage只保存完整响应；网络正文必须精确匹配目录字节数，错误 / 截断正文不写入。写入时移除已解码正文上的Content-Encoding，并重写真实Content-Length / X-Irminsul-Bytes，避免复用被错误解压。旧缓存没有完整标记时先核对正文长度，坏条目删除并重下。

CacheStorage.open / match / 正文校验 / put均有800ms保护，悬挂或配额失败退HTTP，不让后续场景永久等待。运行时取消请求不会禁用正常缓存。角色、背景、生物和音效读取同一版本响应；音乐沿原200ms读取回退 / Blob释放机制。缓存不可用时仍按网络完整下载条件计成功，浏览器HTTP缓存可复用；成功下载不是GPU解码成功的承诺。

成功后清理自有旧版缓存，仅保留当前与最近上一版；不碰存档和其他站点缓存，不缓存API / HTML / 服务器时间。资源错误不会修改服务器权限。
