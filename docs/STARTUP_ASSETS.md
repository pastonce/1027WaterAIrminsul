## 下载、进度与磁盘缓存

StartupLoader 只有三路下载；按响应流真实字节推进，结束 / 失败作为本项准备尝试已完成，进度单调，全部尝试结束才100%。
每文件10秒、总等待60秒；失败 / 空响应 / 204 / 断网不永久黑屏，不伪造成功。之后仍可通过原懒加载 / 静态回退恢复。
进度不复用阶段七元素的模拟停顿，也不会提前写场景就绪收据。

assets:startup 扫描 public/asserts，生成 src/data/startupAssets.generated.json 的大小目录与 docs/startup-assets.manifest.json 的 SHA-256。
缓存名 irminsul-assets-清单修订，只有本版本选定压缩响应进入 CacheStorage。未哈希文件更新时强制刷新HTTP缓存，哈希文件可复用HTTP缓存。
背景 / 生物 / 角色 / 音效在需要时读取同版本响应，角色把本地文本与临时纹理URL交给原Spine播放器，避免三件套预取后又XHR下载一遍。
成功预载后只保留当前与最近上一版的自有缓存，不碰其他站点缓存 / 存档。API、HTML和服务器时间不写缓存；音乐仅写入本页选定的当前一曲压缩响应，不批量解码。
缓存不可用 / 配额不足回退HTTP；原生图片 / CSS字体仍可利用同次HTTP缓存，不持有所有未来图片的解码对象。

## 保留的资源生命周期

- 只对当前场景创建背景 GL、角色或生物实例；未来骨骼 / 图集仅以响应字节保存，未来纹理不解码 / 上传GPU。
- 沿用一个动态背景画布、背景穿插与一个常驻生物画布；当前角色播放器生命周期不变。无新的Canvas / GL / RAF。
- 设置 / 声明、后台、竖屏暂停绘制和交互；开场下载可继续，演出 / 停转 / 游戏计时暂停。换景保持原快照接力与插图遮盖。
- 普通换景仍等服务器日期、已达原段上限并持有完成资格、旧对白全序列、插图解码和新景真实就绪，缓存命中不跳过这些门控。
- 这不是 Service Worker / PWA，不承诺离线重开；/api/time 始终独立校时，缓存不改变权限。
