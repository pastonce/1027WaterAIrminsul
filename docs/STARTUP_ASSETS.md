# 开场集中预载与浏览器负载

## 选择与范围

每次整页打开 / 刷新，在开场下载前 prepareOpeningAssets 忽略旧插图并重抽五组双图、FG 固定，将六组结果写入 v2 loadingArtChoices。同页重复准备不重抽，重置重新抽；允许抽到相同图片并复用缓存，成长 / 对白抽签 / 历史收据不变。
startupPlan 按视口、像素密度、减少动态选择一份计划，单次开场固定，避免重排反复下载。

包含当前设备实际会用到的：
- 六套背景的必要层、对应版本骨骼 / 图集 / 纹理、流图 / 网格和真实静态 poster / 藏身分带；
- 四个新纳西妲、旧梦境与现实角色；十只兰那罗、三只晶蝶及透明姿态；
- 草图标 / E 技能纹样、十张表情、两张甜点、对话底纹、按钮 / favicon、七份压缩音效；
- 常用 WOFF2 与六张已选转场图，每张只一个1280或1920规格；4.0 / 4.1模块只预热，不实例化播放器。
- G 生日来信原书底 / 四导航态、三张已发布贺图，各选 768 或 1280 一档；2026 空图不请求，只在打开对应年时插入贺图 img 解码。

排除落选转场图 / 另一尺寸、BGM、扩展字体、原始MP3 / TTF / 视频、来源 / 署名文档、未使用旧分带与工程截图。
BGM按手势和留白流式播放；扩展字体按 unicode-range 请求。减少动态跳过背景 / 生物动画和4.1，保留来访角色冻结首帧所需三件套及4.0。

## 下载、进度与磁盘缓存

StartupLoader 只有三路下载；按响应流真实字节推进，结束 / 失败作为本项准备尝试已完成，进度单调，全部尝试结束才100%。
每文件10秒、总等待60秒；失败 / 空响应 / 204 / 断网不永久黑屏，不伪造成功。之后仍可通过原懒加载 / 静态回退恢复。
进度不复用阶段七元素的模拟停顿，也不会提前写场景就绪收据。

assets:startup 扫描 public/asserts，生成 src/data/startupAssets.generated.json 的大小目录与 docs/startup-assets.manifest.json 的 SHA-256。
缓存名 irminsul-assets-清单修订，只有本版本选定压缩响应进入 CacheStorage。未哈希文件更新时强制刷新HTTP缓存，哈希文件可复用HTTP缓存。
背景 / 生物 / 角色 / 音效在需要时读取同版本响应，角色把本地文本与临时纹理URL交给原Spine播放器，避免三件套预取后又XHR下载一遍。
成功预载后只保留当前与最近上一版的自有缓存，不碰其他站点缓存 / 存档。API、HTML、音乐和服务器时间不写缓存。
缓存不可用 / 配额不足回退HTTP；原生图片 / CSS字体仍可利用同次HTTP缓存，不持有所有未来图片的解码对象。

## 保留的资源生命周期

- 只对当前场景创建背景 GL、角色或生物实例；未来骨骼 / 图集仅以响应字节保存，未来纹理不解码 / 上传GPU。
- 沿用一个动态背景画布、背景穿插与一个常驻生物画布；当前角色播放器生命周期不变。无新的Canvas / GL / RAF。
- 设置 / 声明、后台、竖屏暂停绘制和交互；开场下载可继续，演出 / 停转 / 游戏计时暂停。换景保持原快照接力与插图遮盖。
- 普通换景仍等服务器日期、严格大于原段成长上限、旧对白全序列、插图解码和新景真实就绪，缓存命中不跳过这些门控。
- 这不是 Service Worker / PWA，不承诺离线重开；/api/time 始终独立校时，缓存不改变权限。
