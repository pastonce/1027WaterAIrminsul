# G 生日来信与贺图书页 · 2026-10-23

## 玩家体验

手机横屏标题、两枚主按钮共用同一竖直中线，四信封排两行两列；桌面仍单行。来信缓存修复：贺图按源地址独立挂载加载状态，`complete / naturalWidth` 处理缓存命中、`decode` 就绪后确认，旧图的迟到回调或超时不能改写新年份；加载过程不再把原图降为半透明。只显示当前单图，真实失败 / 10秒超时仍占位，2026未发布不请求空图。切年、切换图片规格和关闭均清理上一张回调。

G 的「送上生日祝福」上方固定四封信，分别打开 2023～2026 年的来信；信封以独立随机源每 3.2～7.8 秒挑选一封轻晃 950ms，不同步齐动、不消耗对白随机抽签。减少动态不晃动，暂停、后台、竖屏或祝福流程中不继续待机计时。

点击对应信封：启封 280ms → 从该信封位置展开为书页 720ms。全屏浏览层保留 **G 原静态背景**，原人物 / 标题 / 操作暂隐，不截图、换底图或重新创建角色。左页一张完整贺图与轻斜纸框；右页同年「生日邮件」标题 / 全部段落与「贺图回复」，内容多时只在右页纵向滚动。手机横屏正文 11px，书页保持 1103∶677 原比例，640×360 仍可读 / 关闭。

导航复用参考页的叶形灰 / 绿箭头与菱形普通 / 激活态。上一年 / 下一年按 2023→2024→2025→2026→2023 循环，也能点四枚菱形直选；左右方向键与左页横向滑动同样可切换。正文滚动不触发翻页。离场 250ms、新页入场 500ms，参考原页 fade-delay，而非伪造 3D 翻书或自动轮播；切换中不接受重复翻页。

退出按钮 / Escape：收页 350ms → 飞回**最初点击的信封** 620ms → 合封 260ms → 才恢复 G 输入与焦点。途中浏览其他年份不改变回收位置 / 信封配色，调整视口后重新取原按钮几何。展开 / 翻页中请求退出，会先完成当前段再收起，避免跳帧。减少动态各段最多 120ms，仅淡入淡出，仍完整收信。

## 状态、可访问性与暂停

`GameController.openBirthdayMail()` 只允许 G 非回望的 idle，拒绝祝福待播、彩雨、加载、梦醒、设置及挂起状态。进入临时 `mail` 模式，底层 `presentationPaused` 同步暂停日常对白 / 表情 / G 的 20 秒闲置 / 角色。读信不写存档、不标记自动对白已读、不预约祝福；关闭后原句按剩余字时钟续播、闲置从零重新计 20 秒。

`BirthdayMailDirector` 只有一个 `PausableTimer`，负责开合与切年事务；它接收真实后台 / 竖屏挂起，而非一直为 true 的底层 mail 暂停标志。CSS 同步暂停，竖屏保留状态并隐藏浏览层，转屏按钮仍独立可用。重置 / 撤权 / 回望 / stop / 场景卸载取消回调；刷新回到正常 G，不持久化展开状态 / 页码。

浏览层为 `document.body` 下的普通 Portal dialog，不依赖原生 dialog API。背景 inert / aria-hidden；Tab 焦点约束、Escape、退出后回到原信封，正文滚动区域可键盘访问；装饰隐藏于读屏。强制色保留正文、系统配色 / 轮廓导航，旧浏览器不支持容器字体单位时使用显式字号回退。
