## 持久化与工程入口

v2 原对白字段保持；pendingDialogues 新增 opening 类别，仅 A 有效，用于本页无档初入，重新读档时取消。新转场校验目标池，兼容旧预约的来源池；from 仍记录实际出发场景。新增 hasLoadedSave 仅为读档结果、不作为持久日期权限。原轮次、次数、逐句游标、visitLines 和旧普通 ID 迁移保持。

`SaveManager` 对池、阶段归属、顺序、游标与计数做白名单校验，拒绝串池和外链；不提升 v2、不清空既有存档。来访选择 / 已读与祝福结算分别保存；旧已经读完的待访可继续未结算演出，不强行重播旧双句。
