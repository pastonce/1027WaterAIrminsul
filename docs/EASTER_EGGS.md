## 输入

- 不提供说明文本、提示按钮或代码列表的玩家入口。电脑在页面上连续键入，忽略大小写。
- 输入框 / 文本编辑区的键盘不会被全局监听抢走；设置提供一个无 placeholder、无可见说明的输入框，便于手机软键盘使用，保留必要的无障碍名称。
- 首屏右上也可打开设置，保持 intro 不挂载锁定阶段；开放前的手机也能输入 test 进入隔离会话。成功反馈独立 Portal 到 body，避免被设置遮罩压住，不抢焦点。
- 设置输入完整匹配时或按 Enter 验证；无效 / 不适用代码静默，只有成功显示短暂反馈（Birthday 以实际转场作为反馈）。修改键、组合输入、自动连发不触发。
- 开场、后台及竖屏挂起时不兑换；不打断正在进行的换景 / 梦醒事务。没有新增周期轮询、画布或 RAF。

## 内存测试隔离

Birthday 使用独立 `createBirthdaySession`，不是打开 test 调试面板。只为私有 Map / SaveManager 构造已完成 F、仍以 F 为展示收据的临时副本，清除副本旧待播、跳过 F 欢迎；挂载前即准备正常 FG 加载遮盖，加载与 G 首帧双确认后复用同一个 WakingDirector。私有时钟只服务这个预览，不修改 ServerClock、开发时钟 sessionStorage 或正式 v2；原先的未完成事务留在原存档中，刷新按原规则恢复。

不重播整页四叶印、不重复首访公告、不为所有资源重新创建 GL。原设置 / 单规格 FG 缓存沿用；进入 G 可送祝福 / 读信 / 修改临时设置，设置注明「本页生日预览」。再输入 Birthday 可重新演出（正在加载 / 梦醒时不重复触发）；刷新或关闭页面才回原进度，普通浇灌的服务器日期 / 成长规则完全不变。此彩蛋不受公开 test 开关限制，也不自动开启调试工具。

SessionHost 动态加载 createTestingSession 并用新 key 重挂 App，旧音乐 / 交互 / 时钟订阅正确释放。
测试使用私有 Map 的 SaveManager、persist:false 的 DevelopmentClock；不会向 localStorage / sessionStorage 写测试进度或日期，不修改 ServerClock。
复制内容经过 JSON / SaveManager 校验，不和正式对象共享可变子对象。模拟日期只服务测试会话；刷新重新创建正式服务器时钟和原存档。

开发运行仍保留原独立开发存档；隐藏 test 则不论开发 / 生产都切入本页内存会话。
当前公开测试版默认 VITE_PUBLIC_TESTING=true，开屏和 A～G 左上标题显示「（开发测试中）」。
正式收尾可设置 VITE_PUBLIC_TESTING=false 重新构建，关闭公开 test 入口 / 标记；开发模式自身仍有标记与原调试工具。
测试代码只作为动态分块，在正式会话未输入 test 时不主动加载。
