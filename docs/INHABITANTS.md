## 渲染、素材与回退

随机兰那罗使用 manual 模式的 4.0 `CreatureRenderer`，经 `RoamingLayer` **共享已有背景 GL** 并绘在原背景槽位之间；没有新增动画画布或 RAF。C 背景自己仍使用 4.1 解析，角色自己用 4.0；E 背景分段处理时复用同一个受限离屏目标，不把角色染色。F 常驻和晶蝶保留原额外一个透明 4.0 画布。每个形象只在当前需要时加载，共享数据，实例独立时间 / 相位；离屏不绘、不再需要即释放。上限 30 / 20 FPS，额外画布 DPR 1、纹理 1024 / 512，背景自己的质量档保持，同步适配旋转 atlas。

源纹理直通 alpha，透明输出预乘，避免黑边。实例恢复 setup 后按活动 delta 采样 loop；穿插多段时每背景帧只推进一次总时间，不被分段加速。额外透明画布在无变化零时间不重绘；manual 角色随背景清屏重画但不推进暂停时间。普通尺寸 / 镜头只改布局，跨质量档重建，contextlost 后用真实分带静态画面，恢复重建当前形象并保持热点与领奖状态。

减少动态 / 无背景 WebGL 时，用真实背景 `hiding-band-*` 与透明姿态按同样次序交错；不在完整 poster 上再叠一份半透明前景。A 光照另导出 `hiding-light-1.webp`，用 plus-lighter 保留原加色，不产生暗色矩形。原生骨骼失败时，在相同 GL 深度加载自身 poster，不把完整角色抬到前景上。fetch / 解码可取消，骨骼 20 秒 / poster 10 秒上限，代次隔离，释放 texture / buffer / program / bitmap / RAF。独立来访职责与现实角色不变。
