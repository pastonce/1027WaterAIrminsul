本轮将部分E/F演出前移：浇灌次数 / 每次20点 / 日期上限不变，C九浇终点为grow30、D八浇为grow41；E八浇结束于grow45成簇拍，F十浇仍完成grow51及最后7点无动画。原51条木质轨各完整一次，grow42～48分成芽 / 舒叶拍与0.25秒独立成簇拍，共58拍，不停住半次回弹。 树表情仍仅无对白 / 未生长时累计七秒、半概率；完整路线播放期间暂停累计，不新加表情 / 随机时钟，实际验证见TEST_PLAN.md。

## 素材与呈现

来访点击追加对白也可显示纳西妲表情：仅一次追加开播时，从1/2/4/5/6/7抽一张，原主来访不新增自动表情。自然预约保存图片编号 / 已读，恢复同句和重排不重抽；A～F 根据各形态的头部锚点独立定位，避让正在播放的正文与顶栏。沿用同一个 ExpressionDirector / 单张图 / 有界等待 / 暂停 / 清理，不增加GL或RAF；没有替换 G 的句前 / 中 / 后模式，见 NAHIDA_BLESSING.md。

- `asserts/表情包/0.png`～`9.png` 为十张 340×340 透明 PNG，原文件不改。`npm run assets:expressions` 逐字节复制到带哈希的 `public/asserts/expressions/`，登记 `src/data/expressionAssets.generated.json` 和 `docs/expression-assets.manifest.json`。
- 十张发布副本合计 **1,288,382 B**，不新增缩图或有损转码。运行时同屏最多一个表情，开场集中下载十张压缩副本；运行时仍只解码 / 展示实际选中的图片，G 每原句仍只选择一次。
- 白色圆形加指向主体的小三角衬底，单条连续 SVG 圆弧 / 尾尖轮廓、浅绿细边 / 局部阴影，桌面 96 px、手机横屏 70 px；图片完整 contain，不裁原图、不用整张角色图集。表情不接收指针、无按钮 / 焦点、读屏隐藏，不拦截树、角色、梦露或镜头交互。
- 图片就绪后播放 **2800 ms**：小变大 / 轻微回弹与左右晃动，然后停留，最后约 500 ms 渐隐并删除 DOM。图片失败或 2000 ms 仍未就绪则略过，不阻断对白或成长；旧图片回调不能移除更新的表情。
- 随机方向为 **十点至十三点**，12 点朝上为 0°、顺时针为正，即 -60～30°。圆心使用真实树顶或 G 纳西妲头部中心（角色包络横向 48% / 纵向 25%），按树冠 / 头部椭圆包络、气泡尺寸及尾尖另留桌面 22 px / 横屏 16 px 间距；避让顶栏与当前对白正文。只从能完整放入的合法角度重新映射抽选，不平移圆心 / 将表情压回主体；树顶出屏或没有安全角度时隐藏该次表情，不钉在可见树干。树随树高、镜头与入梦地面调整，不加独立入场漂浮。
- 设置、后台 / 竖屏暂停寿命与动效，隐藏而不重建已有表情；恢复只走余量。减少动态保留静态带尾尖气泡和淡入淡出，跳过缩放 / 晃动。无新画布、WebGL、RAF、外链或循环装饰动画。

## 原稿格式

唯一配置仍是 `asserts/对白整合.md`，不用在代码维护第二份正文或阶段候选。数字标记仍不显示在气泡、手记归档和读屏；本轮开始将其同时解析为表情元数据，不改变原编号、文字、标点或抽签 / 已读事务。

```md
## A[13456]
- **N05** [259]谢谢你……[4]接下来的正文……[358]
```

- `[13456]` 表示候选图片 **1、3、4、5、6**，不是编号 13456。候选按每个数字解析并去重，合法范围 0～9。
- 标题后的数字作为该梦境阶段树的空闲候选，生成到 `treeExpressions`。
- 对白中的标记生成 `expressions: [{mode, offset, choices}]`。offset 为移除加粗 / 数字标记后正文的 UTF-16 偏移，与原有打字游标一致；非数字括号原样保留。
- 标记位于全文起点为 before、全文末端为 after，其余为 middle。切成两个气泡显示段不会把全文句中标记误归句后，也不生成新对白 ID。
- 生成命令 `npm run assets:dialogues` / prebuild 会同时更新正文与元数据；只改原稿再生成，不能覆盖源文件来迎合生成清单。

当前树候选：A / B 为 1、3、4、5、6；C 为 0、2、3、4、7；D 为 1、2、5、6、7；E 为 0、1、2、3、8；F 为 1、2、5、7、9。

## A～F 树的累积时钟

1. 正常可交互场景中，树没有任何正在显示的对白（含阅读停留 / 淡出）、未浇灌 / 生长且没有祝福演出时，累计活动时间。
2. 累满 **7 秒**只判断一次，随机值严格小于 **0.5** 才触发。成功后从当前标题候选独立随机一张，失败不展示；两种情况都从零重计下一次 7 秒。
3. 对白、生长、面板 / 后台 / 竖屏期间只暂停累计，不因点击、收露或暂停本身清零。生长收尾门使用当前原动画的真实时长，不再统一等待1200ms树高tween；只添叶或藏叶但高度不增时也正确挂起。
4. 触树对白、浇灌或祝福开始时撤下尚在显示的树表情，避免遮住演出；面板 / 后台仅隐藏并暂停，不当作打断。
5. 转场、梦醒、重置、退出 / 卸载取消时钟与旧表情；新场景重新累计，不跨阶段继承秒数。intro、加载、梦境回访和 G 不运行树的 7 秒判定，不影响原 60 秒待机对白。

## G 的对白同步

仅 G 的 `G/reply` 和 `G/nahida` 使用标记。用户祝福 U 不触发；A～F 来访仍走原祝福流程，不用 G 表情规则。

每条原始对白开始时：先在实际存在的 before / middle / after **模式中均匀选一种**，再从该模式对应方括号的候选中随机选一张。一句话最多一次表情，不对每个标记都播放、不按候选数给模式加权。如果以后同一模式写了多处标记，则先在该模式的标记位置中随机选一处，再选图片。

| 模式 | 时刻 |
| --- | --- |
| before | 原对白开始显示时，不等首字打完 |
| middle | 打字游标到达标记前的正文字符末端；若刚好在两显示段之间，在前段打字结束时触发，不再额外等段间 750 ms |
| after | 末段最后两字即将显示时触发，不等末段 1400 ms 阅读停留 / 淡出结束 |

同步使用原标点呼吸时间线，字速变化、段间停留、悬停和全局暂停仍按原规则。`SpeechDirector` 保留本句选择 / 是否已触发，DOM 重排、当前段重播、悬停恢复不重复抽取 / 弹出；`DialogueBubble` 回报真实可见字符，使系统减少动态的瞬时正文同样在当前显示段内触发，而不把第二段的表情提前到第一段。

表情不是对白事务：不额外抽台词、不增加配额、不标记已读、不提前施法 / 换景，也不改变 G 完整祝福后 20 秒重计规则。仅表情选项和当前动画留在内存，不增加存档字段；刷新继续原句游标，未完成原句按原机制从头播放，其表情重新选择，不追补已读旧句。
