## 检查方法

分别从E入口680和F入口840开始，真实点击浇灌8次 / 10次，关闭减少动态并逐段推进原时钟，不以跨段调试代替中间动画。夹具只禁用自然来访，避免祝福替代浇水而漏掉检查段；正式概率、祝福和存档逻辑不改。日期设在全部开放之后，不依赖解锁边界。

每次记录实际SVG附件、稳定site身份、承接点、矩阵及成长 / 梦露结算，等正常镜头跟随结束再拍场景；grow36 / 42 / 45 / 50另取过程帧。整树诊断页仅复制已渲染SVG并调整viewBox，便于同页检查根、干和冠，不改变游戏镜头或预先拼出树形。

重点不是图片中心是否靠近木质，而是叶柄 / 簇承接点是否连接当前实际显示木枝、叶片是否向外舒展、层次是否错落。承接点始终绑定当前body同一语义枝端UV并随原完整仿射回弹，原attachment切换时才与对应木枝同步切位；不将共有旧叶位移归一化后提前搬向未来树顶，不随机换边 / 排序。新芽等新枝实际cutTime才按原模板弹出。每site只出现当前附件，不以淡入淡出掩盖切图或长期保留base+crown。
