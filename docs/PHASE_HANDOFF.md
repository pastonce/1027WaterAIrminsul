## 2026贺图补入流程

当前 `26.png` 与相关文字保留占位，等负责人取得并处理原图后：

1. 将新图保存为 `asserts/生日贺图/26.png`；如有新信件 / 回复，编辑 `asserts/生日贺图/信与回复.md`。
2. 本地运行 `npm run assets:birthday-art`、`npm run assets:birthday-mail`。
3. 若正文新增字符，运行 `npm run assets:fonts`。执行 `npm run assets:startup` 后用 `npm run release:assets` 检查新旧哈希，只删除报告中经确认的旧生成副本，不动源图。
4. 运行 `npm run build`、`npm run release:audit`，检查G的2026书页实际图片、两设备档、四年切换与退出。
5. 将新生成的 `public/`、`src/data/`、字体CSS及相关docs清单连同正常源码提交，由负责人重新部署。仅上传asserts原图不会更新线上显示。

离线素材工具需要本地完整来源目录与Chrome；普通云端build只需已生成发布副本和两份MD正文，不要求Python / FFmpeg / 原大图。首次生成后更新资源审计，避免遗留旧哈希再次进入部署包。
