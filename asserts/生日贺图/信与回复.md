# 24

## 生日邮件

- 标题：**花车颠啊颠…**
- 内容：
```
睡了吗？我还没睡着，准确来说，是还不想睡呢。
最近的须弥比平常都要热闹，大家像在装饰礼物一样点缀着街道各处。
我原本想要赶在花车巡游前多逛逛，跟大家聊聊天。如果能用我的知识为大家解开一些困惑，会比吃到美味的枣椰蜜糖更令我满足。
不过，我也觉察到大家有事在瞒着我噢。请放心，我是不会偷看的。因为，在拆开礼物盒前，胸口那份藏着小团雀般跃动的期待，也是一种值得细细品味的甜蜜。
花神诞祭是属于大家的节日，我希望所有人都能在今天收获超乎想象的快乐，当然也不能少了你呀...当我早上睁开眼睛之后，能邀请你同游吗？
```

- 内容：
```
兰那罗将『跳房子』的格子从地面拎了起来，筑起一面面彩色的小墙和门洞，是不是该把游戏名字改成『爬房子』才更贴切呢？溪水边也很有趣哦。蕈兽们用圆滚滚的伞帽在水面当小船，载着怕水的小松鼠渡河呢。
你发现了吗？把这样可爱的梦分享给你之后，我们两颗心之间就有一座藤蔓桥悄悄架起来了。
而当须弥蔷薇的微甜包裹着你，星光透过窗棂抚摸你的眼睫时...就是我们的小藤蔓桥最稳固的时候啦。
所以啊，把手上的事情忙完后，好好洗个脸，刷好牙，然后，找一个最松软的枕头，像小鸟筑巢那样，把被窝团成舒服的形状...
我会在桥的另一端，等着你。
```
