# 浇灌一棵世界树 · Water an Irminsul

纳西妲 10.27 生日特别企划的可玩原型。简约、可自行探索的交互：触树、收露、浇灌，纳西妲浮现观察，气泡自动播放 / 消失。非商业同人；对白使用用户提供的 `asserts/对白整合.md`，并非官方原台词，仅机制提示仍为原稿占位。

## 快速开始

当前准备 GitHub / Cloudflare 测试发布：`public/` 与生成清单必须上传，`asserts/` 仅上传构建所需的 `对白整合.md`；本地其余原素材完整保留。`.gitignore` 不会替浏览器拖拽上传过滤文件，请按 [部署清单](docs/DEPLOYMENT.md) 操作，不要上传 node_modules / artifacts / 原始大视频。

使用 Node.js **22.12+**（建议 Node 24）和 npm。当前目录就是项目根目录，不需要再进入子文件夹。

```sh
npm install
npm run dev
```

浏览器打开终端打印的本地地址，默认 http://127.0.0.1:5173 。手机请横屏；需要从其他设备访问时使用 `npm run dev -- --host 0.0.0.0`。

```sh
npm run typecheck
npm test
npm run build
npm run preview
npm run release:audit
```

构建结果在 `dist/`；正式发布还需项目根目录的 `functions/` 与它引用的服务端源码。**不能仅把 dist 拖拽上传为纯静态站点，否则不会有校时接口。** 本轮未部署，由负责人通过 Pages Git 集成或 Wrangler 手动发布，见 [发布与校时说明](docs/DEPLOYMENT.md)。

项目级 `.npmrc` 使用官方 npm registry，无需修改全局配置。美术与运行时均随站点提供，不依赖远程图片或在线字体；生产客户端通过同域 `/api/time` 确认开放时间，无账号或数据库。

若 Windows 全局缓存目录报 EPERM，可使用 `npm install --cache .npm-cache`，将缓存留在项目内，无需修改全局设置。

## 校时与断网

- 首次进入立即请求校时，整个响应读取超时为 5 秒；正常每 60 秒更新，临近开放边界会提前请求，失败每 15 秒重试。网络恢复及回到前台也会校时。
- 同一页面已有校时结果时，断网可继续已确认开放的内容，但不会仅靠时间推算开放新内容。
- 首次校时失败，或刷新后接口仍不可用时，停留入梦页，点击只提示、不进入后续流程。既有成长、梦露和待播回应保留；服务器确认 A 开放后，已有入梦存档自动恢复，新玩家仍需点击入梦，不把存档时间当作权限凭据。
- 设置内可查看状态并「重新校时」；主界面不添加联网弹层、倒计时或成长提示。
- 这不是 PWA 离线缓存功能；离线刷新需页面资源仍可加载。也不是服务端存档或完整防作弊系统，用户仍可自行修改前端程序和本地存档。
